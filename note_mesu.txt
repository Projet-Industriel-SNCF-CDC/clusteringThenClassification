Data Management : 
HOME : $HOME
    Job submission scripts ;
    Personal configuration files (e.g., .bashrc, .profile) ;
    Source code for applications.
    
SCRATCH : $SCRATCH    
    Intermediate data from simulations or analyses.
    Temporary files and job outputs.
    Results not yet saved elsewhere.

STORE : $STORE
    Final project results.
    Raw data collected for future analysis.
    Backups of code and configurations.

Moving data to STORE : 
cd "$STORE"
mkdir backup-scratch
cd backup-scratch
rsync -arv --progress "$SCRATCH/mydata/" .
cd "$SCRATCH"
rm -rf mydata

Data monitoring : 
du -hs $SCRATCH

Job submission : 
job script : 
- the header in which you specify the job requirements (execution time, number of CPU cores to use, memory requirements…) in the form of Slurm directives.
- the body in which you will write the commands to load specific software, define environment variables, and run your job.
https://sacado.sorbonne-universite.fr/documentation-mcmesu/guide/beginner/submitting-a-job
job script generator : 
https://sacado.sorbonne-universite.fr/documentation-mcmesu/guide/beginner/script-generator/


Submit your script/job :
